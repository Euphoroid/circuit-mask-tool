操作と実寸印刷

このHTMLファイルをブラウザーで開くと、インターネット接続なしで利用できます。保存・画像生成・PDF生成もすべて端末内で行います。

T選択範囲を白黒反転。選択がない場合はクリック反転ツールに切り替えます。B / E選択範囲を黒 / 白にします。選択がない場合は黒 / 白の描画ツールに切り替えます。V範囲選択。ドラッグ後に「黒にする・白にする・白黒反転」。Space押しながらドラッグで表示移動。ホイールでも移動できます。Ctrl / ⌘ホイールと組み合わせて、ポインターを中心に拡大・縮小。⌘ / Ctrl Z元に戻す。Shiftを加えるとやり直す。Esc選択を解除。全体の選択は Ctrl / ⌘ A、選択の消去はDelete。

指定したセル幅を固定し、全セルを同じ正方形にします。全体サイズが割り切れない場合は外形をセル幅の整数倍へ切り上げ、作成前に実際の外形を表示します。縮小時は格子線を一定のセル数ごとに間引き表示します。1〜1,000 mm、最小幅0.05 mm以上、最大400万セルに対応します。最小幅は製造品質を保証する値ではありません。

起動時に「新規作成」または「既存編集」を選びます。全体サイズとセル幅は新規作成時だけ設定でき、編集中は固定です。「既存編集」や「データを開く」からJSON形式のマスクデータを読み込めます。旧形式の不均一なセルは、読み込み時に均一なグリッドへ変換し、輪郭の丸め幅を表示します。すべてのセルをクリック・範囲操作で編集し、保存・再読み込みできます。

PDF・SVGはセルの境界に線を描かず、黒の面をそのまま出力します。「左右反転」は銅面の裏側から切る場合に使用します。ガイド付きSVG・PNGにはマスクの外に余白が付きます。マスクの外形寸法は変わりません。

A4 / A3に収まらないPDFは重複なしのタイルに分割します。各ページの「tile origin」は元の図面の左上からの位置です。1枚の大きな図面が必要なら「マスクに合わせる」を選びます。

起動時の自動復元は行いません。ブラウザー内の自動保存データを使う場合は、開始ダイアログの「ブラウザーの保存データを開く」を選んでください。自動保存は同じブラウザー・同じファイルの場所での利用を想定しています。ブラウザーの設定によって使えない場合があるため、編集データ（JSON）を保存すると確実に持ち運べます。直近の操作は最大40回、合計約20 MBまで元に戻せます。
