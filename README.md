# 銅箔マスク工房 / Copper Mask Studio

ブラウザーで銅箔回路マスクを作成するグリッドエディターです。黒を残す銅箔、白を取り除く部分として編集し、実寸のPDF・SVG・PNGを書き出せます。

外部ライブラリーやビルド処理は不要です。`index.html` をダウンロードしてブラウザーで開けば、オフラインでも利用できます。

## 使い方

1. 起動ダイアログで **新規作成** または **既存編集（JSONを開く）** を選びます。
2. 新規作成では横幅・縦幅・セル幅をmm単位で設定します。全体サイズをセル幅の整数倍へ切り上げ、全セルを同じ正方形にそろえます。実際の外形は作成前に表示します。
3. 「反転」「黒」「白」でセルを描画します。ドラッグで連続編集できます。
4. 「範囲」でドラッグするか「数値で範囲指定」でセルを選び、一括で黒・白・反転を適用します。
5. **編集データを保存** でJSONを書き出します。印刷用データは **PDF / SVG / PNG** から保存します。

全体サイズ・セル幅は編集中には変更できません。別サイズで作る場合は「新規作成」を選びます。図面を切り替えると元に戻す履歴はリセットされるため、必要な図面は先にJSONで保存してください。

## キーボード

| 操作 | キー |
| --- | --- |
| 選択範囲を黒 / 白 / 反転 | B / E / T |
| 選択がない場合のツール切り替え（黒 / 白 / 反転） | B / E / T |
| 範囲選択ツール | V |
| 選択解除 | Esc |
| 全体を選択 | Ctrl / ⌘ A |
| 選択範囲を白にする | Delete / Backspace |
| 元に戻す | Ctrl / ⌘ Z |
| やり直す | Ctrl / ⌘ Shift Z、Ctrl / ⌘ Y |
| 表示移動 | Space＋ドラッグ、またはホイール |
| 拡大・縮小 | Ctrl / ⌘＋ホイール、または画面の＋・− |

文字入力中やダイアログ表示中は編集ショートカットを適用しません。

## 保存とプライバシー

- **起動時にはデータを自動で読み込みません。** JSONを選ぶか「ブラウザーの保存データを開く」を押した場合だけ既存データを開きます。
- 編集内容は利用中のブラウザーのローカル保存領域にも自動保存します。別の図面を作成・読み込みすると自動保存データも置き換わります。
- JSONの読み込み、画像生成、PDF生成は端末内で処理します。アプリには図面をサーバーへ送信する処理やアクセス解析はありません。
- GitHub Pages版を開くときは、HTMLをGitHubから取得するための通信が発生します。
- ローカルHTML版とPages版など、開く場所・ブラウザーが違う場合は自動保存を共有しません。図面の移動やバックアップにはJSONを使ってください。
- 起動ダイアログで何も開かずに閉じた場合、保存データは上書きしません。

## 寸法・出力

- 横幅・縦幅は1〜1,000 mm、セル幅は0.05 mm以上、最大400万セルです。
- PDF・SVGは実寸のベクター出力です。編集用のグリッドと選択枠は含まれません。
- PDFはA4・A3・図面に合わせた用紙サイズに対応します。1枚に収まらない場合は縮小せずに分割します。
- 印刷時は **実際のサイズ / 100%** を選び、出力した50 mm定規を実測してください。
- PNGは150 / 300 / 600 dpiを選べます。最大一辺16,384 px・4,000万画素です。確認用グリッドも付けられます。
- 「左右反転して出力する」は書き出しにだけ適用し、編集画面は反転しません。
- 旧形式のJSONは0.635 mm角の均一セルへ変換し、輪郭の丸め幅を表示します。
- 元に戻す履歴は最大40回・約20 MBです。

このツールは形状編集用です。電気的な接続・極性・製造可能な幅は自動検査しません。

## 開発

```text
index.html                  エディター本体（CSS・JavaScriptを含む）
tests/editor.test.cjs        外部依存のない動作テスト
.github/workflows/pages.yml テストとGitHub Pagesへの公開
```

Node.js 22でテストを実行できます。パッケージのインストールは不要です。

```sh
node --test tests/editor.test.cjs
```

テストは簡易DOM上で実際のイベント処理を実行し、起動・読み込み・範囲操作・履歴などを確認します。テストデータはコード内で生成した単純な図形です。ブラウザーの描画・印刷結果は別途確認してください。

## GitHub Pagesへの公開

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
2. `main` にPushします。テスト成功後、Pagesへ自動デプロイします。
3. 公開URLはActionsのデプロイ結果またはSettings → Pagesで確認できます。

ワークフローは[GitHub公式のPages設定](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)に沿って構成しています。公開用アーティファクトには `index.html`・`LICENSE`・`.nojekyll` だけを含めます。

`.gitignore` は公開するソースファイルだけを許可する構成です。個人のマスクデータ、参照PDF、認証情報、作業ファイルをコミットしないでください。新しいソースファイルを追加するときは内容を確認してから許可リストに追加します。`git add -f` で除外を解除しないでください。
